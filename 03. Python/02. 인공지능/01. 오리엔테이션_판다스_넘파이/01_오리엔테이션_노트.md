## 이 차시에서 배운 것

**주피터 노트북 환경**
- 셀 단위 실행 — 마지막 줄의 값은 `print()` 없이도 출력된다 (`df`만 쳐도 표가 나옴)
- 마크다운 셀로 설명을 함께 적는다 (`#` 제목, `>` 인용, `-` 목록)

**판다스 — 표(DataFrame) 만들기**
```python
df = pd.DataFrame(data)                                    # 중첩 리스트로
df = pd.DataFrame(data, columns=[...], index=[...])        # 열·행 이름 지정
df = pd.DataFrame({'과목':[...], '점수':[...]}, index=[...]) # 딕셔너리로
```
- 이름을 안 주면 열과 행 이름이 `0, 1, 2…` 숫자가 된다
- `columns='이름 나이 성별'.split(' ')` — **05장에서 배운 `split()`이 여기서 쓰입니다**

**열 고르기**
| 코드 | 결과 |
|---|---|
| `df['과목']` | **Series** (1차원) — 출력에 `Name: 과목, dtype: object` |
| `df[['과목','학급']]` | **DataFrame** (표) — 대괄호가 **두 겹** |

**행·열 동시에 고르기 — `loc`과 `iloc`**
| 코드 | 뜻 |
|---|---|
| `df.iloc[2]` | 위치 2번 **행** (integer location) |
| `df.loc['4반','성별']` | **이름**으로 행·열 지정 |
| `df.loc[:, ['과목','학급']]` | 모든 행 + 지정한 열 |
| `df.loc[['영희','민수'], [...]]` | 이름 목록으로 여러 행 |
| `df.iloc[1:, :]` | 1번 행부터 끝까지 (슬라이싱) |
| `df.iloc[1:, [0,2]]` | 행은 슬라이싱, 열은 번호 목록 |

→ **앞은 행(index), 뒤는 열(column)** 순서. `loc`은 이름, `iloc`은 번호.

**넘파이 — 왜 필요한가**
```python
a = np.array([1,2,3,4,5,6])
b = a * 100          # 반복문 없이 전체에 한 번에
```
2차원도 똑같이 `aa * 5` 한 줄로 끝납니다.

## 이 수업의 의도 — 지금까지 배운 것이 여기서 회수된다

`01. 기본문법`을 쭉 보면 **"손으로 먼저 → 도구로 다시"** 패턴이 반복됩니다. 이 차시도 정확히 같은 구조입니다.

| 장 | 손으로 | 도구로 |
|---|---|---|
| 02 → 03 | `while True` + `break` | `for` + `range` |
| 08 → 09 | 반복문으로 교집합 | `&` 연산자 한 글자 |
| 09 → 10 | 리스트 `index()` 반복 | 딕셔너리 키 조회 |
| **이번** | **이중 `for`문으로 행렬 계산 (셀 11~12)** | **`np.array` × 5 (셀 14)** |

셀 10~14가 이 차시의 **심장**입니다. 넘파이를 바로 가르치지 않고 **먼저 리스트로 고생시킨 뒤** 꺼내 보여 주는 순서예요. 셀 12의 주석 "리스트로 접근하면 행렬을 게산할 수 없다"와 셀 14의 "넘파이와 판다스가 필요한이유"가 그 결론입니다.

그리고 **앞 장들이 여기서 전부 쓰입니다.**

| 앞에서 배운 것 | 여기서 쓰이는 곳 |
|---|---|
| 중첩 리스트 (05~06장) | `pd.DataFrame(data)`의 입력 |
| 딕셔너리 (09~10장) | `pd.DataFrame({'과목':[...]})`의 입력 |
| `split()` (05장) | `columns='이름 나이 성별'.split(' ')` |
| 슬라이싱 (04~05장) | `df.iloc[1:, :]` |
| 이중 for문 (03장) | 셀 11~12 — 그리고 그걸 버리는 이유 |

> "그때 그걸 왜 배웠나" 싶었던 것들이 **데이터 분석의 입력 형식**이었던 셈입니다.

## 다시 확인해 볼 것

- **셀 11 — 결과가 `[[], [], [], 5, 10, 15, …]`로 나옵니다.** `b = [[],[],[]]`로 빈 리스트 3개를 먼저 만들어 놓고, 거기에 `b.append(j*5)`로 **숫자를 바로** 붙였기 때문입니다. 빈 리스트 3개가 앞에 그대로 남아 있죠. 셀 12에서 `tmp`를 쓴 것과 비교하면 무엇이 달랐는지 보입니다. (지운 코드가 아니라 **시도의 기록**이니 그대로 두는 게 좋습니다.)

- **셀 05의 `df[1]`** — 여기서 `1`은 "두 번째"가 아니라 **열 이름 그 자체**입니다. 셀 04에서 이름을 안 줘서 열 이름이 숫자가 된 거죠. 셀 06에서 이름을 붙인 뒤 `df[1]`을 다시 해 보면 에러가 납니다. 왜인지 설명할 수 있어야 `loc`/`iloc`이 왜 따로 있는지 이해됩니다.

- **셀 09에 주석으로 남은 세 가지** — 세 방법이 모두 `'여'`를 돌려주지만 성격이 다릅니다.
  ```python
  df['성별']['4반']   # 열을 꺼내고 → 그 안에서 행을 찾음 (두 단계)
  df.iloc[3, 2]      # 번호로 한 번에
  df.loc['4반','성별'] # 이름으로 한 번에
  ```
  실무에서 권하는 건 `loc`/`iloc`입니다. 첫 번째 방식은 값을 **바꿀 때** 경고가 뜨는 경우가 있습니다.

- **오타 몇 개** — 주석의 `padas` → `pandas`, `게산` → `계산`, `뉴메리컬 포 파이썬`은 **Num**erical **Py**thon이라 "넘파이"라는 이름이 나온 유래입니다. 주석은 나중에 다시 읽을 내 메모니 고쳐 두면 좋습니다.

## 더 연습하고 발전시킬 것

1. **`Series`와 `DataFrame`을 구분하는 눈.** 대괄호 한 겹이면 Series, 두 겹이면 DataFrame입니다. `type(df['과목'])`과 `type(df[['과목']])`을 찍어 비교해 보세요. 앞으로 "왜 표가 아니라 한 줄로 나오지?" 할 때 전부 이 차이입니다.

2. **`loc`과 `iloc`을 섞어 쓰지 않는 습관.** 이름을 쓸 거면 끝까지 `loc`, 번호면 끝까지 `iloc`. 섞으면 가장 찾기 힘든 버그가 됩니다.

3. **`df.shape`, `df.info()`, `df.head()`, `df.describe()`** — 아직 안 나왔지만 표를 받으면 **가장 먼저** 하는 네 가지입니다. 지금 만든 `df`에 한 번씩 해 보세요.

4. **조건으로 행 고르기** — 다음에 거의 확실히 나옵니다.
   ```python
   df[df['점수'] >= 90]
   ```
   04장에서 "조건에 맞는 원소만 새 리스트에 담기"를 반복문으로 했던 것의 판다스 버전입니다. 그때 코드와 나란히 놓고 보면 좋습니다.

5. **넘파이 브로드캐스팅** — `aa * 5`가 왜 모든 원소에 퍼지는지가 "브로드캐스팅"입니다. `aa + aa`, `aa * aa`, `aa.T`(전치), `aa.shape`도 해 보세요. 오리엔테이션의 **벡터·내적**이 바로 이 이야기로 이어집니다.

6. **`.ipynb`는 `.py`와 다릅니다.** 셀을 위아래로 왔다 갔다 실행하면 변수가 뒤섞입니다. 이 노트북에서도 `data`와 `df`가 여러 번 덮어써졌죠. 헷갈리면 **커널 재시작 후 위에서부터 전부 실행**해 보는 습관을 들이세요.
