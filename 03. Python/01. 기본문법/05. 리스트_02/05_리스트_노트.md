# 05. 리스트_02 — 문자열 · 집계 · 무작위

## 이 장에서 배운 것

- **문자열 메서드**: `replace()`, `split(구분자)` — `split`은 문자열을 **리스트로** 만든다
- **슬라이싱으로 자릿수 뽑기**: `data[:4]`, `data[4:6]`, `data[6:8]`
- **집계 내장 함수**: `max()`, `min()`, `sum()`, `len()` — 직접 반복문으로 구한 버전과 비교
- **`random` 모듈 세 형제**
  - `random.choice(리스트)` — 하나 뽑기
  - `random.choices(리스트, k=2)` — 중복 **허용**
  - `random.sample(리스트, 2)` — 중복 **없음**
- `datetime.now()`로 현재 시각 가져와 문자열로 가공
- `.format()`에서 **인덱스 지정**: `"{1} {0}".format(a, b)`
- **중첩 리스트(리스트 안의 리스트)** 와 이중 인덱싱 `a[4][1]`, `a[-1][-2]` — 06장 예습

## 다시 확인해 볼 것

- **`05_리스트_ex_02.py` (핵심)**: 세 줄로 나눠 담는 게 목표인데
  ```python
  a = a + data[i]      # i
  b = b + data[i+3]    # ← i+1 이어야 하지 않나요?
  c = c + data[i+2]    # i+2
  ```
  `b`만 `i+3`입니다. 출력해 보면 `b`가 `a`를 한 칸 늦게 따라가는 걸 볼 수 있습니다. 그리고 `range(0, len(data)-2, 3)` 의 `-2`가 왜 필요한지도 설명할 수 있어야 합니다 (`data`는 19글자, 3의 배수가 아님).
- **`숙제/05_리스트_숙제_예습_01.py`와 `02.py`를 꼭 비교**하세요. `a.append(tmp)`는 리스트를 **통째로 원소 하나**로 넣고, `a += tmp` 는 원소들을 **풀어서** 넣습니다. 06장의 `06_리스트_ex_01.py`가 바로 이 차이를 쓰는 문제입니다.
- `05_리스트_ex_01.py`의 `data=data.replace(' ','').replace(':','')` — **메서드 체이닝**(점을 이어 붙이기)입니다. 왜 가능한지(각 `replace`가 새 문자열을 돌려주니까) 이해하고 넘어가세요.

## 더 연습하고 발전시킬 것

1. **`split()`과 `join()`은 짝**입니다. `split`은 배웠으니 `", ".join(리스트)`로 되돌리는 것도 해 보세요. 리스트를 예쁘게 출력할 때 계속 씁니다.
2. **문자열 메서드 한 바퀴**: `strip()`, `upper()`, `lower()`, `find()`, `startswith()`. 입력값 정리할 때 필수입니다.
3. **음수 인덱스 익히기**: `a[-1]`, `a[-2]`. `숙제/05_리스트_숙제_예습_02.py`에서 맛만 봤는데, 리스트 길이를 몰라도 뒤에서 접근할 수 있어 아주 편합니다.
4. `05_리스트_ex_01.py`의 날짜 포맷을 직접 슬라이싱하는 대신 `datetime`의 `strftime()`으로도 해 보기 — "이미 있는 도구를 찾아 쓰는" 감각 연습입니다.
5. **변수 이름**: `a`, `b`, `c`, `n` 같은 한 글자 이름이 많습니다. 짧은 실습에선 괜찮지만, `05_리스트_ex_02.py`처럼 세 개가 각자 다른 뜻을 가지면 `line1`, `line2`처럼 붙이는 게 나중의 자신에게 친절합니다.
