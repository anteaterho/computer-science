# 10. 딕셔너리 (2) — 전체를 훑고, 두 리스트를 묶기

현재 진도의 **가장 마지막 장**입니다. 09장이 "키 하나로 값 하나 꺼내기"였다면, 이 장은 **딕셔너리 전체를 다루는 법**입니다.

## 이 장에서 배운 것

- **세 가지 꺼내기 메서드**
  | 메서드 | 얻는 것 |
  |---|---|
  | `d.keys()` | 키만 |
  | `d.values()` | 값만 |
  | `d.items()` | (키, 값) 짝 |
  → 그대로는 `dict_keys([...])` 같은 특수한 형태라, 인덱싱하려면 `list()`로 감싼다
- `len(딕셔너리)` — 항목 개수
- **집계로 연결**: `sum(list(d.values()))` — 05장에서 배운 `sum`을 딕셔너리에 적용
- **`zip()`으로 두 리스트 묶기**: `dict(zip(fruits, price))`
  → 09장 숙제(`09_딕셔너리_숙제_02.py`)에서 쓴 기법을 이 장에서 정면으로 다룸
- 딕셔너리를 **메뉴판/조회표**로 쓰기 — 이름을 입력받아 가격을 찾는 주문 프로그램

- **`10_딕셔너리_ex_08.py` — 메뉴에 없는 걸 주문하면 `KeyError`로 프로그램이 죽습니다.**

  - 힌트 1: `if order in menu:` 로 먼저 확인하기
  - 힌트 2: `menu.get(order, 0)` 으로 없으면 0 처리하기
  - 어느 쪽이 사용자에게 더 친절할지 생각해 보세요 (조용히 0원 처리 vs "그런 메뉴 없어요" 안내)
- **`y`/`n`이 아닌 걸 입력하면** — `if y: continue`, `if n: break` 뿐이라 둘 다 아니면 조용히 다음 주문으로 넘어갑니다. 의도한 동작인가요? `else`로 안내 문구를 넣어 주면 좋습니다.

## 더 연습하고 발전시킬 것

1. **`for` + `items()` 반복 — 아직 안 써 봤습니다. 이 장의 가장 큰 빈칸입니다.**
   ```python
   for name, price in menu.items():
       print(name, price)
   ```
   07장의 **언패킹**이 여기서 다시 쓰입니다. 메뉴판 출력, 최고가 상품 찾기, 조건에 맞는 항목만 고르기 — 전부 이 한 패턴입니다.
2. **딕셔너리 정렬**: `sorted(d.items(), key=lambda x: x[1])` — 가격순 메뉴판. `lambda`가 낯설면 먼저 "값 기준으로 정렬하려면 뭘 알려줘야 할까?"부터 생각해 보세요.
3. **개수 세기(counting)를 딕셔너리로.** 06장은 리스트로, 08~09장은 세트로 했던 일입니다.
   ```python
   for w in words:
       cnt[w] = cnt.get(w, 0) + 1
   ```
   `get(키, 기본값)` 의 진가가 여기서 나옵니다. 글자 빈도, 단어 빈도, 투표 집계 — 실전 단골 문제입니다.
4. **`10_딕셔너리_ex_08.py`를 제대로 된 프로그램으로 키우기** (지금까지 배운 걸 전부 쓰는 종합 과제)
   - 메뉴판 먼저 출력 (`items()`)
   - 없는 메뉴 처리 (`in` 또는 `get`)
   - 주문 목록 저장 (리스트 `append`)
   - 마지막에 "아메리카노 x2 = 8000" 식 영수증 (`format` 정렬)
   - 같은 메뉴를 몇 잔 시켰는지 세기 (딕셔너리 counting)
5. **`zip()` 더 써 보기**: 이름·점수 두 리스트를 묶어 성적표 만들기, `zip(*...)` 로 다시 풀기.
