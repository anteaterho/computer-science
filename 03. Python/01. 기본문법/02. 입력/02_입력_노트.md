# 02. 입력

## 이 장에서 배운 것

- `input()`은 **무조건 문자열(str)** 을 돌려준다 → 계산하려면 `int()` / `float()`로 바꿔야 한다
- 형변환 위치의 차이: `a = input(); a = int(a)` vs `a = int(input())`
- `type()`으로 자료형 확인하기
- 따옴표 안에 따옴표 넣기: `\"` 이스케이프, 또는 바깥을 `'`로 감싸기
- `ord()` / `chr()` — 문자와 아스키 코드 번호 사이 변환
- 반복문 맛보기: `while True` + `break`, `for i in range(1,16)`
- `print(i, end=" ")` — 줄바꿈 대신 공백으로 이어 출력

## 다시 확인해 볼 것 (실행하면 바로 드러납니다)

- **`02_입력_ex_03.py`**: `if age >= '20'` 은 **문자열끼리 비교**입니다. `9`를 입력하면 어떻게 될까요? 사전 순으로 비교하기 때문에 `'9' > '20'`이 참이 됩니다. 그리고 다음 줄 `elif 14 < age` 는 숫자와 문자열 비교라 `TypeError`로 멈춥니다. → **비교 전에 `int()`로 바꿔야 한다**는 것이 이 장의 핵심입니다.
- **`02_입력_ex_04.py`**: `a/b`에서 `a`, `b`는 아직 문자열입니다. 곱셈 줄에서는 `int()`를 씌웠는데 나눗셈 줄에서는 빠졌습니다. 또 `{:.2}`는 `{:.2f}`와 의미가 다릅니다(유효숫자 2자리 vs 소수점 2자리). 둘 다 출력해서 비교해 보세요.
- **`숙제/02_입력_homework_01.py`**: 답은 맞게 나오지만, 실은 **운 좋게** 맞는 코드입니다. 누적 변수와 입력 변수를 둘 다 `a`로 쓰고 있어서 `range(a)`가 언제 정해지는지 헷갈리기 쉽습니다. 합계는 `sum` 같은 별도 변수에 모으는 습관을 들이세요. 그리고 `a < 100` 조건 때문에 "100 이하"인데 **100이 제외**됩니다.

## 더 연습하고 발전시킬 것

1. **입력 즉시 형변환하는 습관**: `n = int(input("숫자: "))` 한 줄로. 이 장 이후의 모든 문제가 편해집니다.
2. **한 줄에 두 값 입력받기**: `a, b = input().split()` → `a, b = map(int, input().split())`. (03장 `03_반복_ex_18.py`에서 이미 쓰고 있으니 여기서 원리를 확실히 해 두기)
3. **누적 변수 이름 규칙 만들기**: 합은 `total`, 개수는 `cnt`처럼. `sum`은 파이썬 내장 함수 이름이라 변수로 쓰면 나중에 `sum()`을 못 씁니다.
4. `while True` + `break`와 `for` + `range`로 **같은 문제를 두 번 푸는 연습** — `02_입력_ex_07/08`이 바로 그 연습입니다. 앞으로도 계속 하면 좋습니다.
