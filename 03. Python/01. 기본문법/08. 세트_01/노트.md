# 08. 세트 (1) — 세트를 배우기 전에, 리스트로 먼저

이 장은 특이합니다. **세트 문법을 쓰지 않고, 리스트와 `for` + `in`만으로 집합 연산을 손으로 구현**했습니다.
다음 장(`09. 세트_02`)에서 같은 일을 `&`, `|`, `-` 한 글자로 끝내게 되는데, **그 대비가 이 장의 목적**입니다.

## 이 장에서 배운 것

- `in` / `not in` 을 걸러내기 조건으로 쓰기
- 리스트로 손수 만든 집합 연산
  ```python
  for i in a:
      if i in b: c.append(i)      # 교집합
  for i in a:
      if i not in b: e.append(i)  # 차집합
  ```
- **중복 제거 패턴** (`숙제/08_세트_homework_01.py`)
  ```python
  for i in language:
      if i not in result:
          result.append(i)
  ```
  → 순서를 지키면서 중복을 없애는 고전적인 방법

## 다시 확인해 볼 것

- **`08_세트_ex_01.py`의 `d = a + []`** 는 지금 아무 데도 쓰이지 않습니다. 합집합을 만들려다 만 흔적 같습니다. 주석의 두 시도
  ```python
  for i in b:
      if i != a: d.append(i)      # ← 원소와 리스트를 비교하고 있음
  for i in b:
      if i not in a: d.append(i)  # ← 이게 맞는 방향
  ```
  **`!=`와 `not in`의 차이**가 정확히 드러나는 좋은 기록입니다. 위쪽이 왜 안 되는지 설명할 수 있어야 합니다.
- 합집합은 결국 완성하지 않았습니다. 09장 문법을 보기 **전에** 리스트만으로 한번 완성해 보세요.

## 더 연습하고 발전시킬 것

1. **이 장의 코드를 09장 문법으로 다시 쓰고 줄 수를 세어 보기.** 12줄이 1줄이 됩니다. 이 체감이 세트를 배우는 이유 그 자체입니다.
2. **잃는 것도 알아두기.** 세트는 빠르고 짧지만 **순서가 사라지고 중복이 없어집니다.** `숙제/08_세트_homework_01.py`의 리스트 방식은 *입력 순서를 그대로 유지*하는데, `set()`으로 바꾸면 그 순서가 깨집니다. 어떤 문제에서 순서가 중요할지 생각해 보세요.
3. **속도 차이 알아보기**: `if i not in 리스트`는 원소를 처음부터 하나씩 훑지만, `if i not in 세트`는 한 번에 찾습니다. 원소가 10만 개일 때 두 방식의 시간을 재 보면 차이가 극적입니다.
4. 24와 36의 약수를 **직접 구하는 코드**부터 써 보기 (지금은 손으로 적어 놨습니다). 03장의 반복문 + 나머지 연산 복습이 됩니다. 이어서 최대공약수(GCD)까지 구해 보세요.
