# 09. 세트 (2) — 세트 문법

08장에서 반복문으로 힘들게 만들었던 것을 **연산자 한 글자**로 끝내는 장입니다.

## 이 장에서 배운 것

- `set(리스트)` 로 세트 만들기 — **중복이 자동으로 사라진다**
- **집합 연산자 네 개**
  | 연산 | 기호 | 뜻 |
  |---|---|---|
  | 교집합 | `a & b` | 양쪽에 다 있는 것 |
  | 합집합 | `a \| b` | 둘 중 하나라도 있는 것 |
  | 차집합 | `a - b` | a에만 있는 것 |
  | 대칭차집합 | `a ^ b` | 한쪽에만 있는 것 |
- **원소 추가/삭제**
  - `add(하나)` vs `update({여러 개})`
  - `remove(x)` — 없으면 **에러**
  - `discard(x)` — 없어도 **조용히 넘어감**
- `set` → `list()` 로 되돌려 순서 있는 자료로 쓰기
- `type()`으로 `<class 'set'>` 확인

## 다시 확인해 볼 것

- **`숙제/09_세트_과제풀이.py`가 리스트 방식 그대로입니다.** 세트를 배운 장인데 08장 숙제와 코드가 똑같습니다. `set()` 한 줄로 바꿔 보고, **결과가 어떻게 달라지는지** 확인하세요 — 중복은 사라지지만 **순서도 바뀝니다**. 그래서 "순서를 지키면서 중복만 없애려면?" 이라는 다음 질문이 생깁니다. (`list(dict.fromkeys(...))` — 10장 딕셔너리를 배운 지금이면 이해할 수 있습니다.)
- 그리고 `'c++, python, C, python, C++, C'` — 08장 원본은 `'C++'`(대문자)였는데 여기는 `'c++'`(소문자)가 섞여 있습니다. 파이썬에게 `'C'`와 `'c'`는 **다른 값**이라 결과가 달라집니다. 의도한 것인지 확인해 보세요.
- **`09_세트_ex_02.py`**: `remove`를 주석 처리하고 `discard`로 바꿨는데, 둘의 차이는 **없는 값을 지울 때** 드러납니다. `colors.remove('purple')`을 실행해서 에러 메시지를 직접 보세요. 그게 이 줄의 요점입니다.
- **`09_세트_ex_03.py`**: `p.add("Joule")` 주석 위에 `p = list(p)` 가 있었습니다. 리스트로 바꾸면 `add`가 안 되고 `append`를 써야 합니다 — 자료형마다 쓸 수 있는 메서드가 다르다는 것.

## 더 연습하고 발전시킬 것

1. **"언제 세트인가"를 판단하는 감각.** 이 셋 중 하나면 세트를 떠올리세요.
   - 중복을 없애야 한다
   - "있는지 없는지"만 빠르게 확인하면 된다
   - 두 모음을 비교해야 한다 (공통/차이)
2. **세트에 못 들어가는 것**: 리스트를 `set`에 넣어 보고 에러를 확인하세요. 07장에서 배운 "바뀌지 않는 값만 원소가 될 수 있다"와 이어집니다.
3. **메서드 형태도 있습니다**: `a.intersection(b)`, `a.union(b)`, `a.difference(b)`. 연산자 기호가 안 떠오를 때 쓸 수 있고, 남의 코드에서 자주 봅니다.
4. **실전 문제로 연습**: 두 반의 명단에서 양쪽 다 참석한 학생, 한쪽만 온 학생 뽑기. 문자열에 쓰인 서로 다른 글자 세기 (`set("hello")`).
5. **세트 → 딕셔너리로 넘어가는 다리.** 세트는 "있다/없다"만 압니다. "몇 개인지, 값이 뭔지"까지 알고 싶으면 → 딕셔너리(09~10장). 같은 중복 제거 문제를 `set`으로도 풀고 딕셔너리로 **개수까지 세는** 버전으로도 풀어 보면 차이가 선명해집니다.
