# 06. 리스트_03 — 중첩 리스트와 함수의 등장

이 장이 **전환점**입니다. 여기서 처음 `def`로 함수를 만들기 시작했고, 문제도 "출력하기"에서 "**값을 계산해 돌려주기**"로 성격이 바뀝니다.

> 이 장의 숙제와 숙제 노트는 [`숙제/`](./숙제/) 폴더에 있습니다.

## 이 장에서 배운 것

- **중첩 리스트 조작**: 깊은 곳의 원소를 꺼내 바깥으로 끌어내기, `a += [6, 9]` 로 여러 개 한 번에 붙이기
- **초기 리스트 만드는 세 방법** (`06_리스트_ex_02.py`에 나란히 있음)
  ```python
  for i in range(len(score)): rank.append(1)   # 반복문
  rank = [1 for i in range(len(score))]        # 리스트 컴프리헨션
  rank = [1] * len(score)                      # 곱셈
  ```
- **`def` 함수 정의 / 매개변수 / `return`** — 그리고 `return`은 함수를 즉시 끝낸다는 것
- **누적 대신 세기(counting) 배열**: `cnt = [0] * n` 만들고 `cnt[값] += 1`
- **`index()`로 최댓값의 위치 찾기**: `cnt.index(max(cnt))`
- **나머지 연산으로 그룹 나누기**: `cnt[i % n] += tb[i]` — 순환 배치 패턴
- **조건 분기를 단순화하기**: `if normal > small: return normal ... ` → `return max(normal, small)`

## 다시 확인해 볼 것

- **`ex_05`, `ex_06`, `ex_07` 파일에 `.py` 확장자가 없습니다.** 문법 색칠도 안 되고 실행도 번거로우니 이름을 고쳐 두세요.
- **`06_리스트_ex_03.py`**: 매개변수 이름이 `scroe`로 오타가 났고, 함수 **안에서는 전역 변수 `score`를 쓰고** 있습니다. 지금은 우연히 돌아가지만 함수에 다른 리스트를 넣으면 무시당합니다. 함수는 **바깥 변수를 몰라야** 재사용할 수 있다 — 이게 `ex_02` → `ex_03` 변환의 진짜 요점입니다. `ranker([10, 50, 30])`을 실행해 확인해 보세요.
- **`06_리스트_ex_02.py`의 등수 로직**: 동점(87이 둘)일 때 결과가 어떻게 나오는지 확인하고, 그게 원하는 규칙인지 판단해 보세요.
- **`06_리스트_ex_06.py`**: `cnt = [0] * (3+1)` 에서 후보 수 3이 코드에 박혀 있습니다. 후보가 5명이면? `max(votes)`를 써서 자동으로 맞추는 방법을 생각해 보세요. 또 동표일 때 `index()`는 앞쪽 하나만 돌려줍니다.
- **`06_리스트_ex_05.py`의 반복문 버전**: `while usage:` 는 "0이 아닌 동안"이라는 뜻입니다. 사용량이 1000이면 1000번 돕니다. 수학식 버전과 비교해 **어느 쪽이 왜 나은지** 말할 수 있으면 좋습니다.

## 더 연습하고 발전시킬 것

1. **함수로 만드는 습관**. 앞 장들에서 풀었던 문제(3·6·9 게임, 자릿수 합, 소수 판별)를 전부 `def solution(...)` 형태로 다시 써 보세요. 프로그래머스식 문제 형식에 익숙해지는 가장 빠른 길입니다.
2. **지역변수 / 전역변수 구분**. `ex_03`의 오타가 좋은 출발점입니다. 함수 안에서 바깥 변수를 건드리면 무슨 일이 생기는지 직접 실험해 보세요.
3. **세기 배열(counting) 패턴**이 이 장의 최대 수확입니다. `ex_06`의 방식을 기억해 두면 — 08~10장에서 이걸 **딕셔너리로** 다시 하게 되고, 그때 "리스트로는 정수 인덱스만 되는데 딕셔너리는 아무 키나 된다"는 차이가 확 와닿습니다.
4. **리스트 컴프리헨션**은 `ex_02` 주석에 한 번 등장했습니다. 지금은 반복문 버전을 먼저 확실히 하고, 나중에 "같은 걸 짧게 쓰는 법"으로 다시 보세요. 급하지 않습니다.
5. `ex_02`의 등수 매기기는 이중 루프라 원소 수가 늘면 느려집니다. `sorted()`를 써서 더 빠르게 하는 방법을 고민해 보면 좋은 훈련입니다.
