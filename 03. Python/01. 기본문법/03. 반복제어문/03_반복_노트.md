# 03. 반복제어문

이 저장소에서 **가장 두꺼운 장**입니다. 파일 수도 많고 난이도 편차도 큽니다.

## 이 장에서 배운 것

- `for i in range(시작, 끝, 증가폭)` — 끝 값은 **포함되지 않는다**
- 역방향 반복: `range(100, a-1, -1)`
- **이중 for문** — 바깥 루프 한 번에 안쪽 루프 전체가 돈다, `print()`로 줄바꿈
- `while True` + `break` / `continue`
- `flag` 변수 패턴 — "조건을 만족하는 게 하나라도 있었나?"를 기록
- 자릿수 분해 두 가지 방법
  - 수학적: `n % 10`으로 끝자리 떼고 `n // 10`으로 줄이기
  - 문자열: `for j in str(i)` 로 한 글자씩
- `map(int, input().split())` 으로 여러 값 한 번에 입력
- `random.randint()`, `random.randrange()`
- 소수 판별, 최소공배수, 등차·등비수열 합 같은 **알고리즘적 문제**

## 다시 확인해 볼 것

- **`03_반복_ex_13.py` (중요)**: `for j in str(i)` 에서 `j`는 **문자열 한 글자**입니다. 그런데 `if j == 1` 로 **숫자 1**과 비교하고 있습니다. 실행하면 언제나 `0`이 나옵니다. `숙제/03_반복_homework_01.py`에서는 `if j == '3'` 처럼 따옴표를 제대로 붙여 놨으니, 두 파일을 나란히 놓고 비교해 보세요.
- **`03_반복_ex_15.py`**: `sum = s47um + ...` — 오타 때문에 `NameError`로 멈춥니다. 그리고 문제 의도상 `k = int(input())`으로 받은 값을 `for k in range(4,11)`이 곧바로 덮어써서 입력값이 전혀 쓰이지 않습니다.
- **`03_반복_ex_20.py`**: 비어 있습니다. 놓친 문제인지 확인해 보세요.
- **`sum`을 변수 이름으로 쓴 파일이 여럿**입니다(`ex_12`, `ex_14`, `ex_15`, `숙제/test.py`). 동작은 하지만 그 파일 안에서 내장 함수 `sum()`을 못 쓰게 됩니다. `total` 또는 `s`로 바꾸는 습관을 권합니다.

## 더 연습하고 발전시킬 것

1. **`flag` 패턴을 확실히 내 것으로.** `숙제/03_반복_homework_01.py`와 `숙제/test.py`에서 같은 구조가 반복됩니다. "안쪽 루프에서 하나라도 찾으면 `break` → 바깥에서 `flag` 확인"은 앞으로 계속 나오는 필수 패턴입니다.
2. **자릿수 다루기 두 방법을 모두 유창하게.** `%10`/`//10` 방식과 `str()` 방식. 같은 문제를 두 방법으로 풀어 보세요 (`ex_12`와 `ex_13`이 이미 그 짝입니다).
3. **이중 for문 도형 그리기**: 직각삼각형 별, 역삼각형, 피라미드, 구구단 전체 표. `03_반복_ex_09.py`의 연장선입니다.
4. **`break`와 `continue`의 차이**를 한 파일에서 실험해 보기 — 주석으로 결과를 적어 두면 좋습니다.
5. **`for ... else` 문법**은 아직 안 배웠습니다. `flag` 패턴에 익숙해진 다음에 보면 "아, 이걸 대신하는 거구나" 하고 이해됩니다.
6. 문제 번호가 09번부터 시작하는 것은 02장(입력)에서 08번까지 이어 매긴 번호를 그대로 물려받았기 때문입니다. 04장부터는 장마다 01번으로 새로 시작합니다.
