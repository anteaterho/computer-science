# 01. 출력

## 이 장에서 배운 것

- `print()` 기본 사용과 여러 값을 쉼표로 이어 출력하기
- 줄바꿈 문자 `\n`, 빈 `print()`로 한 줄 띄우기
- 문자열 반복 연산자 `*` — `"CBRAiN Python" * 3`, `"=" * 11`
- 숫자를 문자열에 끼워 넣는 세 가지 방법
  - 그냥 쉼표로 나열: `print("My height is", h, "cm.")`
  - `%` 포매팅: `%d`, `%.1f`, `%.2f`
  - `.format()`: `{}`, `{:.1f}`
- `end=` 옵션은 다음 장(02. 입력)에서 등장

## 다시 확인해 볼 것

- **`01_출력_ex_06.py` 마지막 줄**: 몸무게를 출력하는데 단위가 `cm`으로 적혀 있습니다. `%` 포맷 문자는 맞지만 뒤에 붙는 글자를 확인해 보세요.
- **`01_출력_ex_05.py`**: `"CBRAiN Python\n" * 5`는 `for`문 버전과 출력이 **미묘하게 다릅니다**. 직접 둘 다 실행해서 마지막 줄 아래를 비교해 보세요. (힌트: 마지막 `\n`)
- 영어 철자 오타 몇 개: `Welcom` → `Welcome`, `virture` → `virtue`, `ohters` → `others`. 코드는 돌아가지만 출력물은 남의 눈에 보이는 결과물입니다.

## 더 연습하고 발전시킬 것

1. **포매팅 하나를 주력으로 정하기.** 지금은 `%`와 `.format()`을 섞어 쓰고 있습니다. 둘 다 이해했으니, 앞으로는 `.format()` 하나로 통일해서 손에 익히면 좋습니다. (f-string은 수업 진도에서 나올 때 배우면 됩니다.)
2. **정렬 옵션 연습**: `{:>10}`, `{:<10}`, `{:^10}` 로 성적표를 표처럼 줄 맞춰 출력해 보기.
3. **`sep=` 옵션**: `print(a, b, c, sep=", ")` — `end=`와 짝이 되는 옵션입니다.
4. `01_출력_ex_08.py`의 성적표를 `=` 줄로 감싸서 영수증처럼 꾸며 보기 (04번의 `*` 반복 활용).
