# 04. 리스트_01

## 이 장에서 배운 것

- 리스트 만들기와 인덱싱 `a[2]`
- 원소 추가: `append()` (끝에) vs `insert(위치, 값)` (끼워 넣기)
  - `a[2] = 33`은 **덮어쓰기**, `a.insert(2, 33)`은 **밀어 넣기** — `04_리스트_ex_01.py`에서 직접 비교
- 원소 삭제: `remove(값)` vs `del a[인덱스]` vs `del a[1:4]` (슬라이스 삭제)
- 정렬: `sort()`, `reverse()`, `sort(reverse=True)` — 모두 **원본을 바꾼다**
- 반복문으로 리스트 만들기: 빈 리스트 → `for` → `append`
- 문자열도 리스트처럼 다룰 수 있다: `len()`, 인덱싱, 슬라이싱 `a[8:14]`
- `in` / `not in` 으로 포함 여부 확인, `count()`로 개수 세기

  ```python
  for i in range(1,4,1): del a[1]     # 같은 자리를 세 번 지움
  for i in range(3,0,-1): del a[i]    # 뒤에서부터 지움
  ```

  반복문 안에서 리스트를 지우면 **인덱스가 밀린다**는 점 — 실전에서 정말 자주 실수하는 부분이니 왜 뒤에서부터 지워야 안전한지 설명할 수 있어야 합니다.

## 더 연습하고 발전시킬 것

1. **원본을 바꾸는 함수 vs 새 값을 돌려주는 함수** 구분하기.
   - `a.sort()` → `None` 반환, 원본 변경
   - `sorted(a)` → 새 리스트 반환, 원본 유지
   - `a.append(x)`도 마찬가지입니다. `a = a.append(x)` 라고 쓰면 `a`가 `None`이 됩니다. 한 번 실행해서 확인해 보면 평생 안 잊습니다.
2. **슬라이싱 집중 연습**: `a[:3]`, `a[3:]`, `a[-2:]`, `a[::2]`, `a[::-1]`. 05장에서 문자열 자르기로 바로 쓰입니다.
3. **"조건에 맞는 것만 골라 새 리스트" 패턴**을 손에 익히기 (`ex_01`의 짝수 고르기). 이후 모든 장에서 반복됩니다.
4. `04_리스트_ex_02.py`처럼 **주석으로 시도 과정을 남기는 습관**은 아주 좋습니다. 계속 유지하세요.
