# 09. 딕셔너리 (1) — 키로 값 찾기

리스트는 **번호(0, 1, 2…)** 로 값을 찾았습니다. 딕셔너리는 **이름(키)** 으로 찾습니다.
06장에서 만들었던 `cnt = [0] * n` 세기 배열의 한계 — "정수 번호만 쓸 수 있다" — 를 벗어나는 장입니다.

> 같은 09차시에 [`09. 세트_02/`](../09.%20세트_02/)가 따로 있습니다. 세트 마무리와 딕셔너리 시작이 같은 날에 걸친 것으로 보입니다.

## 이 장에서 배운 것

- 딕셔너리 만들기: `{'메로나': 600, '폴라포': 800}` — **키: 값** 짝
- 값 꺼내기 `ice['빵빠레']`, 값 바꾸기/추가하기 `ice['죠스바'] = 600`
  - **없는 키에 대입하면 새로 생긴다** — 리스트와 결정적으로 다른 점
- 여러 개 한 번에: `update({'죠스바':600, '월드콘':1200})`
- 삭제: `del ice['메로나']` vs `ice.pop('메로나')` (`pop`은 지운 값을 돌려줌)
- **중첩 딕셔너리** — 값 자리에 리스트나 또 다른 딕셔너리 넣기
  ```python
  ice2 = {'메로나': {'가격':600, '재고':20}, '비비빅': [500, 3]}
  ice2['비비빅'][1]      # 리스트 → 번호로
  ice2['메로나']['재고']  # 딕셔너리 → 이름으로
  ```
  → 같은 데이터인데 이름으로 꺼내는 쪽이 훨씬 읽기 쉽다는 걸 체감하는 부분

## 숙제 두 개가 가르치는 것

### `09_딕셔너리_homework_a.py` — 주사위 게임
`set(dice)`로 **서로 다른 눈이 몇 종류인지** 세어 경우를 나누는 발상이 좋습니다.
- 잘한 점: 주석 처리된 첫 시도에서 `l_dice[i] == dice[i]` 로 세려다 실패한 뒤, **`dice.count(p)`** 로 바꿔 해결했습니다. 문제를 다시 정의해서 푼 셈입니다.
- 확인해 볼 것: `set`을 `list`로 바꾼 `l_dice`의 **순서는 보장되지 않습니다.** `l_dice[1] * l_dice[2]` (눈이 3종류일 때)가 항상 의도한 두 수를 가리킬까요? 어떤 값을 곱해야 하는지 문제 조건을 다시 읽고, 안전하게 고르는 방법을 생각해 보세요.
- `return` 이후 실제로 실행해 보는 코드가 없습니다. 아래에 `print(solution(2,2,2,2))` 같은 테스트를 몇 줄 넣어 두면 확인이 쉽습니다.

### `09_딕셔너리_homework_b.py` — 달리기 경주 (**가장 중요한 코드**)
리스트로 푼 버전이 주석에 남아 있습니다.
```python
pos = players.index(i)   # ← 매번 처음부터 훑는다
```
선수가 10만 명이면 이 한 줄 때문에 시간 초과가 납니다. 그래서 **딕셔너리 두 개로 양방향 지도**를 만들었습니다.
```python
dic1 = 이름 → 등수
dic2 = 등수 → 이름
```
추월이 일어날 때마다 **두 지도를 함께 갱신**하는 것 — 이게 이 장 전체의 결론입니다. `zip()`과 `dict(zip(...))`도 여기서 처음 나왔고 10장에서 다시 다룹니다.

- 확인해 볼 것: `dic2`(딕셔너리)를 그대로 반환하는데, 문제는 보통 **이름 리스트**를 원합니다. 등수 순으로 정렬된 리스트로 바꿔 보세요.
- 확인용 `print(dic1)`, `print(dic2)`는 제출 전에 지우는 습관을.
- 1등이 추월당하면 `pos - 1`이 `-1`이 됩니다. 실제로 그런 입력이 들어올 수 있는지 문제 조건을 확인해 보세요.

## 더 연습하고 발전시킬 것

1. **"리스트의 `index()`나 `in`이 반복문 안에 있으면 딕셔너리를 떠올린다"** — 이 감각 하나만 챙겨도 이 장은 성공입니다.
2. **없는 키 접근 대비**: `ice['없는것']` 은 `KeyError`로 멈춥니다. `ice.get('없는것', 0)` 을 써 보세요. 10장 `10_딕셔너리_ex_08.py`에서 바로 필요해집니다.
3. **키로 쓸 수 있는 것 / 없는 것**: 문자열·숫자·튜플은 되고 리스트는 안 됩니다. 07장 튜플, 09장 세트와 같은 이유입니다.
4. **딕셔너리로 개수 세기** 연습 — 06장의 투표 집계를 딕셔너리로 다시 풀어 보세요. 후보 번호가 아니라 후보 *이름*으로 셀 수 있게 됩니다.
5. 중첩 딕셔너리로 **재고 관리 프로그램** 만들어 보기: 상품마다 가격·재고를 넣고, 판매하면 재고를 줄이고, 다 팔리면 목록에서 지우기.
